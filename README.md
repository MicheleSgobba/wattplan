# WattPlan

Piano di allenamento per il ciclismo basato su FTP e tempo disponibile.

**App:** https://michelesgobba-ship-it.github.io/wattplan/

Installazione sul telefono:
- iPhone: apri il link in Safari › Condividi › Aggiungi alla schermata Home
- Android: apri il link in Chrome › menu ⋮ › Installa app

I dati restano sul dispositivo di chi usa l'app.
